# Scene VRM Example App

## Running

```
flutter create . --platforms=macos # platforms may be added as needed.
```

```
flutter run --enable-flutter-gpu
```

### MacOS

#### Enable file access

Open the project in Xcode and go to Signing & Capabilities -> App Sandbox to set the “User Selected File” permission to “Read Only”.
